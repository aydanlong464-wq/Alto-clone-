# Custom surfer model

Put a GLB file here named **`surfer.glb`** and the game uses it instead of the built-in glossy figure. It only loads when the game is served from a web address (GitHub Pages or a local web server). Opening `index.html` straight from your disk can't read this folder.

To try a model without uploading it, drag the `.glb` onto the game window, or tap **Load 3D model**.

## Making one with Meshy

1. Generate a character, e.g. *"glossy green 3D person, smooth rounded limbs, Windows Vista icon style, standing sideways in a surf stance"*.
2. Export as **GLB**.
3. Save it here as `models/surfer.glb`, or drop it onto the game.

The game scales the model to about 1.7 m tall and stands it on the board. If it faces the wrong way, press **R** to turn it 90°.
